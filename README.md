*Eternal Launcher is a Windows, Linux launcher for Minecraft (Electron + React): vanilla, Fabric, Forge, NeoForge, Quilt, Modrinth and CurseForge catalogs, Horizon (Rust) builds. Download: [eternal-launcher.com/launcher](https://eternal-launcher.com/launcher).*

## Установка
1. Скачайте установщик на странице https://github.com/xandersd3v/EternalLauncher-Linux/releases.
2. Запустите файл `Eternal-Launcher-Setup-<версия>.appImage` через chmod +x `Eternal-Launcher-Setup-<версия>.appImage` в директории скачивания.

## Возможности
- **Аккаунты:** Microsoft и оффлайн (до 5 оффлайн-аккаунтов). Оффлайн-аккаунт работает в одиночной игре и на серверах с отключённой проверкой лицензии Mojang.
- **Сборки:** создание, импорт, обновление; моды, ресурспаки и шейдеры с Modrinth и CurseForge.
- **Скины и плащи**, галерея скриншотов, статистика игры, мониторинг памяти и процессора.
- **Настройки игры («эталон»)** для новых сборок, общий список серверов для всех сборок, выбор Java для каждой сборки.
- **Автообновление** лаунчера с проверкой цифровой подписи (Ed25519).
- Часть косметики (плащи, сердечки, цвет ника) доступна по подписке на сайте Eternal; скины Eternal работают только на основном оффлайн-аккаунте.

## Сборка из исходников
Нужны Linux и npm (проверено на версии 24). Лаунчер рассчитан на Linux, Windows; macOS пока не поддерживаются.

```powershell
npm ci
npm run dev              # окно с горячей перезагрузкой (работает заметно медленнее обычного запуска)
npm run build:renderer   # собрать интерфейс
npm start                # запустить собранную версию
npm run dist             # собрать установщик в папку release
```

Установщик собирается без цифровой подписи Windows, поэтому SmartScreen может показать предупреждение.

## Что лаунчер отправляет в сеть
Здесь описано всё, что лаунчер делает по сети, чтобы вы могли проверить это по исходникам. Счётчиков, аналитики и рекламных сервисов в коде нет.

**Игровые и каталожные сервисы** (по мере использования, напрямую с вашего компьютера):
- Mojang и Microsoft: версии игры, библиотеки, ресурсы, вход в Microsoft-аккаунт (сам вход проходит на страницах Microsoft; пароль лаунчеру не передаётся).
- Fabric, Quilt, Forge, NeoForge: списки версий и установщики. Если официальный адрес недоступен, списки версий запрашиваются у зеркала BMCLAPI, а файлы установщиков можно получить через сайт Eternal; их контрольные суммы проверяются.
- Modrinth, CurseForge (нужен свой бесплатный API-ключ), Technic: поиск и загрузка модов и сборок.
- GitHub и сайты проекта Horizon: загрузка официальных сборок Horizon.
- Java: для обычных сборок лаунчер берёт среду у Mojang; для сборок Horizon при необходимости загружает Java с Adoptium или Microsoft.
- Если пользоваться функцией перевода описаний, их текст отправляется в Google Translate.
- Защищённый DNS (DNS-over-HTTPS) через серверы Cloudflare и Google включён в автоматическом режиме: он помогает найти адрес сайта там, где системный DNS не справляется.

**Сайт Eternal (`aestmc.ru`).** Лаунчер обращается к нему, только если вы входите в аккаунт сайта или пользуетесь функциями Eternal:
- вход и проверка подписки: логин и пароль (или вход через Telegram), выдача лицензии;
- **идентификатор устройства:** при проверке лицензии на сайт отправляется хэш (SHA-256, первые 32 символа) от идентификатора установки Windows (`MachineGuid`) с добавлением соли `eternal-launcher-device`. Это нужно, чтобы привязывать лицензию к устройству. Сам `MachineGuid`, имя компьютера и список программ не отправляются;
- скины, плащи и сердечки основного оффлайн-аккаунта (публикация на сервере скинов);
- проверка обновлений лаунчера (файл `latest.json` с подписью).

## Готовые файлы в репозитории
Обычно собранные файлы в репозиторий не кладут. Здесь три исключения, и вот почему:

| Файл | Размер | SHA-256 | Зачем |
|---|---|---|---|
| `build/agent/eternal-agent.jar` | 2 КБ | `11bc0d23342972da371b757889e34e006c95f3e54c7afa9676b504113516ac1c` | точка входа агента (`premain`) |
| `build/agent/eternal-core.jar` | 180 КБ | `7a53e2241de9f9d14ef02e7feb2ac089bfe100cd586cc06061f74e47f90603b8` | ядро агента, внутри библиотека ASM (BSD) |
| `build/tools/rcedit-x64.exe` | 1,3 МБ | `ab53500d556fd824636621bca7dbecd8583ba181891c3e9efdcf16b72a28b0cd` | утилита rcedit (MIT): прописывает иконку и версию в `.exe` при сборке установщика |

- Оба `.jar` собираются из `eternal-agent/src` командой `npm run build:agent` (нужен JDK 17+; компилируется под Java 8, ASM берётся из библиотек лаунчера). Они лежат готовыми, чтобы установщик можно было собрать без JDK. Побайтно пересобранный файл может отличаться от этого (зависит от компилятора), поэтому сверяйте не хэш, а исходники.
- `rcedit-x64.exe` взят из проекта electron/rcedit без изменений; хэш можно сверить с официальным релизом.
- Если вы не доверяете готовым файлам, пересоберите агент сами и замените их.

## Свой сервер и ключи
Адрес сайта Eternal и публичные ключи подписи обновлений и лицензий вшиты в `electron/updateConfig.js`, `electron/updatePublicKey.js`, `electron/licensePublicKey.js`. Если вы делаете собственную сборку, замените их на свои. Приватные ключи подписи в репозиторий не входят.

## Сторонние компоненты
Зависимости перечислены в `package.json` и распространяются под своими лицензиями (в основном MIT; шрифты Manrope и Unbounded под SIL OFL; DOMPurify под MPL-2.0 или Apache-2.0). Horizon в репозиторий не входит: лаунчер скачивает его официальные сборки с GitHub. Скины Steve, Alex и остальные стандартные персонажи принадлежат Mojang Studios.
